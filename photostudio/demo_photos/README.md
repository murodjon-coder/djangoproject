# Demo suratlar

Bu papkadagi 11 ta surat **sun'iy intellekt bilan yaratilgan** (Higgsfield, *Soul 2.0* modeli, 2026-10-19).
Ulardagi odamlar haqiqiy emas. Suratlar faqat namoyish (demo) uchun ishlatiladi: `python manage.py seed_demo` ularni
galereyaga joylaydi. Mavjud suratlarning rasmini almashtirish uchun: `python manage.py seed_demo --rasmlarni-yangilash`.

Sayt bezagi uchun `static/images/` papkasida yana uchta rasm bor: `studio.jpg`, `backstage.jpg` va `garden.jpg`.
